# PDF Redactor — обезличивание сканов договоров аренды

Веб-сервис, который готовит скан договора аренды к передаче третьим лицам, например в
муниципальную службу. Он находит на каждой странице суммы и персональные данные
собственника и предлагает закрыть их чёрными прямоугольниками. Пользователь проверяет и
правит закраску в браузере, убирает лишние страницы и скачивает PDF, из которого закрытое
нельзя восстановить.

**Демо:** https://pdf.sverbin.ru — песочница. Не загружайте туда реальные документы с
чужими персональными данными: сервис для этого рассчитан на установку в своей сети.
Для пробы есть вымышленный договор
[examples/sample_contract.pdf](examples/sample_contract.pdf) (все имена и номера выдуманы,
генератор — [examples/make_sample.py](examples/make_sample.py)).

## Что умеет

- Принимает PDF-сканы без текстового слоя: договор аренды нежилого помещения или акт
  приёма-передачи.
- Распознаёт все страницы (Tesseract OCR, русский и английский) и сам выравнивает
  перекошенные сканы и фотографии.
- **Закрывает:** денежные суммы (цифрами, прописью, таблицы смет); паспортные данные, дату и
  место рождения, адреса регистрации и для корреспонденции, телефон и e-mail собственника.
- **Оставляет:** ФИО, ИНН, ОГРНИП, банковские реквизиты, адрес и площадь объекта, данные
  арендатора, подписи и печати.
- Редактор в браузере: плашки можно двигать, менять размер, удалять и рисовать новые.
  Ненужные страницы исключаются одной кнопкой. Для договора сервис подсказывает, какие
  страницы обычно нужны: первую и страницу с подписями сторон.
- Итоговый PDF собирается только из картинок: плашки нарисованы прямо в пикселях, текстового
  слоя, исходных изображений и метаданных нет. Снять закраску в PDF-редакторе нельзя.
- Очередь задач: несколько пользователей обслуживаются по очереди, каждый видит свою позицию.
  Задачи переживают перезапуск сервиса.
- Не требует внешних сервисов. По желанию подключается локальная LLM с OpenAI-совместимым
  API как дополнительный слой поиска.

Правила поиска рассчитаны на типовую форму договора, где арендодатель — индивидуальный
предприниматель, а арендатор — компания. На других формах часть данных может остаться
незакрытой. Именно поэтому перед скачиванием обязательна проверка человеком.

## Быстрый старт

### Docker

```bash
git clone https://github.com/s-verbin/pdf-redactor.git
cd pdf-redactor
docker compose up -d --build
```

Откройте http://localhost:8088. Tesseract и языковые модели ставятся внутри образа.

### Без Docker (для разработки)

Нужны Python 3.11+ и Tesseract OCR 4+.

```bash
# 1. Tesseract
brew install tesseract                     # macOS
sudo apt install tesseract-ocr             # Ubuntu / Debian
# Windows: установщик UB Mannheim — см. docs/setup.md

# 2. Языковые модели rus и eng в папку tessdata/ проекта
mkdir -p tessdata
curl -L -o tessdata/rus.traineddata https://github.com/tesseract-ocr/tessdata/raw/main/rus.traineddata
curl -L -o tessdata/eng.traineddata https://github.com/tesseract-ocr/tessdata/raw/main/eng.traineddata

# 3. Окружение и зависимости
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# 4. Проверка окружения — подскажет, чего не хватает
.venv/bin/python -m app.check

# 5. Запуск
.venv/bin/uvicorn app.main:app --port 8088
```

Вместо скачивания моделей в `tessdata/` можно поставить русский язык вместе с Tesseract
(`apt install tesseract-ocr-rus`, галочка *Russian* в установщике Windows). Если папка
`tessdata/` пуста, сервис берёт системные модели.

Подробная инструкция для Windows, macOS и Linux и запуск из VS Code (F5) — в
[docs/setup.md](docs/setup.md).

### Из командной строки

```bash
.venv/bin/python -m app.cli договор.pdf                    # все страницы
.venv/bin/python -m app.cli договор.pdf --keep suggested   # стр. 1 и страница с подписями
.venv/bin/python -m app.cli договор.pdf --debug debug      # + PNG закрашенных страниц
```

## Как это работает

```
PDF → рендер страниц → выравнивание наклона → OCR (линии таблиц стёрты)
    → поиск: белый список для абзаца о собственнике, регулярки (суммы, паспорт, адреса…),
             ячейки таблицы реквизитов, опционально LLM
    → проверка и правка в браузере → закраска в пикселях → PDF только из картинок
```

## Стек

Python, FastAPI, PyMuPDF, Tesseract OCR, Pillow, NumPy; фронтенд на чистом JS без сборки.
